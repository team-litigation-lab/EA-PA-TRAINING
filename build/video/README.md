# 🎬 Narrated day videos

Each day of the course has a **Video Presentation**: the day's lesson deck, exactly as the room sees it in Presenter
view, with a natural American English voice speaking every slide from the trainer's speaker notes (the 🎙 *Script —
read aloud*, `js/days/dayN/scripts.js`), compressed where the notes repeat themselves. It is the Case Management
course's ▶ Video, made the same way, from this course's own decks.

- **On the dashboard**, each day card has **🔒 Video** until a trainer unlocks that day's video, then **▶ Video**
  (trainers always see ▶). **Unlocking:** Admin → 🛡 Admin Master Control → **🎬 Videos**: pick *Every batch* or one batch
  and tick the days (or Unlock all / Lock all). It's kept in `settings:openvideos` = `{all: [days], batches: {"<batch>":
  [days]}}`, which every trainee can read and only a trainer can write (`worker.js` `PUBLIC_READ`); a trainee's page
  picks a change up within two minutes. The viewer (`js/eapa-day-video.js`) has captions in a strip under the slide (CC
  turns them off), a Slide picker to jump to any slide, ⏪ / ⏩ 10 s, speed 0.75× to 2×, ⛶ Full screen, and it reopens
  where the viewer left off on that device. Remove its `<script>` tag in `index.html` to take the videos off.
- **The files**: `videos/dayN-narrated.mp4` (1280 × 720, under the 25 MB asset limit) and `videos/dayN-narrated.vtt`
  (captions); `js/eapa-day-videos.js` lists them with each slide's start time (generated by `publish.cjs`).
- **The narration**: `build/video/narration/dayN.json`, one entry per slide page, written to
  [`NARRATION.md`](NARRATION.md): the speaker notes' own words and cadence, the repeats between the *why*, the
  explanation and the walk-through cut, live-room prompts turned into prompts for one viewer, nothing added.
- **The voice**: [Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0), voice `af_heart`, run offline on a
  CPU: nothing is sent anywhere. `make_video.py`'s `SAY` table says how a term is spoken (`BLUF` → "bluff", `IT` →
  "I T"); the captions keep it as written.

## Rebuilding a day

After changing a day's slides or its narration:

```bash
node .github/scripts/server.mjs 8787 &
```

```bash
node build/video/capture.cjs 3 build/video/out
```

```bash
python3 build/video/make_video.py --day 3 --frames build/video/out/day3 --out build/video/out/video/day3 --web
```

```bash
node build/video/publish.cjs
```

`capture.cjs` screenshots every slide page at 1920 × 1080 from the Presenter view slides window and writes
`raw.json` (each page's script, as Presenter view splits it). If the slides changed, the narration file must still
have one entry per frame, in order: update `narration/dayN.json` to match. `make_video.py` keeps each frame's audio
in `<out>/audio`, keyed by its text, so a rebuild only voices the frames whose narration changed. Then raise
`js/eapa-day-videos.js`'s `?v=` in `index.html`.

Setup (Python 3.10–3.12, `ffmpeg`):

```bash
pip install kokoro soundfile "misaki[en]"
```
